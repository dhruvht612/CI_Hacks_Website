# CI Hacks Website

Hackathon registration and application platform focusing on registration, participant profiles, and application status tracking.

## Frontend

The frontend is a React application built with Vite.

### Features

- **Landing Page** — Hackathon information, event highlights, key dates, and registration call-to-action
- **Authentication** — Sign up, sign in, and sign out
- **Dashboard** — Application status overview and quick actions
- **Profile** — Create and edit participant information
- **Responsive Design** — Works on desktop, tablet, and mobile

### Getting Started

```bash
cd frontend
npm install
npm run dev
```

The app runs at [http://localhost:3000](http://localhost:3000).

### Build

```bash
cd frontend
npm run build
```

### Tech Stack

- React 18
- React Router 6
- Vite 5

**Note:** The frontend currently uses local storage for demo purposes. Connect to the backend API when available.
